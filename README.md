# 테마 스튜디오 3.13.4 (Marinara Engine 확장)

Marinara Engine 개인 확장입니다. (2.4.x ~ 2.5.1까지 호환 확인)

마리나라의 색상·타이포그래피·말풍선·코드블럭을 **화면을 보면서 실시간으로** 고치고, 완성본을 **마리나라 테마 JSON**으로 내보내는 테마 편집기입니다. 내보낸 테마를 설정 > 테마에서 가져와 적용하면 그 뒤에는 이 확장을 꺼도 지워도 테마가 그대로 남습니다. 확장은 편집 도구일 뿐, 결과물은 순정 테마 파일입니다.

## 들어가는 자리

- 화면 오른쪽 아래에 **팔레트 모양 버튼**이 떠 있습니다. 누르면 편집 패널이 열리고, 다시 누르면 닫힙니다.
- 패널은 화면 오른쪽에 붙어 열리며, 머리 부분을 끌어서 옮기고 모서리를 끌어 크기를 바꿀 수 있습니다. 크기는 기억됩니다.
- 머리의 **최소화** 버튼을 누르면 머리만 남아 화면 전체를 확인할 수 있습니다.

## 패널 구성

| 머리 부분 | 설명 |
| --- | --- |
| 다크 / 라이트 탭 | 어느 모드의 값을 고칠지 고릅니다. 앱의 모드를 바꾸면 탭도 따라갑니다. 색 항목은 모드별로 따로 저장되고, 폭·간격 같은 항목은 두 모드 공통입니다. |
| 항목 검색 | 이름으로 항목을 찾습니다. |
| 변경 사항 N개 | 지금까지 바꾼 값의 수. 바꾼 행은 초록으로 표시됩니다. |
| 시작값 다시 읽기 | 현재 테마에서 기본값을 다시 읽습니다. 테마를 바꾸면 자동으로도 다시 읽습니다. |
| 모두 되돌리기 | 바꾼 값을 전부 지웁니다. |
| 테마 이름 + 내보내기 | 마리나라 테마 JSON(`Marinara_테마_이름.json`)을 내려받습니다. 옆의 복사 버튼은 테마 CSS만 클립보드로 복사합니다. |

각 행에는 **색 스와치 또는 입력칸**, 👁(그 항목이 화면 어디인지 깜빡여 보여 줌), 바꾼 행에만 나타나는 ↺(이 항목만 되돌리기)가 있습니다. 색 행에는 투명 버튼이 있고, 숫자 행에는 −/＋ 단계 버튼과 단위 표시가 있습니다. 행에 마우스를 올리면 전체 이름과 짧은 설명이 뜹니다.

## 내보내기와 적용

1. 패널에서 값을 고칩니다. 바뀐 값은 즉시 화면에 반영되고, 확장 저장소에 저장되어 새로고침해도 유지됩니다.
2. 테마 이름을 적고 **내보내기**를 누릅니다. 바꾼 값이 하나도 없으면 내보낼 수 없습니다.
3. **설정 > 테마**에서 내려받은 JSON을 가져와 적용합니다.
4. 적용이 끝나면 확장을 꺼도 됩니다. 테마는 "지금 적용 중인 테마의 CSS 원본 + 바꾼 값 블록"으로 만들어지므로, 원래 테마 위에 수정분이 얹힌 완성본이 됩니다.

같은 테마를 여러 번 내보내도 이전에 얹었던 수정 블록은 자동으로 걷어내고 새로 얹습니다. 테마 없이(순정 상태에서) 시작하면 수정 블록만으로 된 테마가 됩니다.

## 알아둘 점

- **미리보기와 내보내기는 같은 CSS를 씁니다.** 확장이 화면에 꽂는 스타일이 곧 내보낼 내용이라, 보이는 대로 저장됩니다.
- **글꼴은 기기에 있거나 마리나라가 로드한 것만** 적용됩니다. 없는 글꼴 이름을 적으면 CSS가 조용히 무시하고 기본 글꼴로 보입니다. 굵기 550 같은 중간값은 가변 폰트에서만 실제로 달라집니다.
- **CONVO 말풍선 항목이 "화면에 요소 없음"이면** 설정 > 모양 > 대화 표시 > 채팅 레이아웃이 말풍선(버블)형이 아닌 것입니다. 클래식 레이아웃에는 말풍선 요소 자체가 없습니다.
- 어떤 값이 안 바뀌어 보일 때는 👁로 그 항목이 화면 어디를 가리키는지 먼저 확인하고, 다크/라이트 탭이 앱 모드와 같은지 보세요. 적용 중 오류가 나면 알림으로 뜹니다.
- 패널 안 항목은 2.4.6 기준으로 엔진 변수·클래스를 전수 확인했습니다. 이후 엔진이 변수 이름이나 클래스를 바꾸면 해당 행만 안 먹게 되고, 변수라면 "변수 직접 추가"로 바로 대응할 수 있습니다.
- 액센트 펄스처럼 엔진이 테마 CSS를 **텍스트로 읽어** 처리하는 기능은 이 확장의 실시간 미리보기와 맞지 않아 넣지 않았습니다. 그런 값은 내보낸 테마 CSS를 직접 편집하세요.

## 확장이 기대는 화면 표식

- 적용 중인 테마: `<style id="marinara-custom-theme">`. 확장은 `<style id="mts-live-style">`를 `<head>` 맨 끝에 유지해 테마보다 뒤에서 이깁니다.
- 다크/라이트 판별: `<html data-theme>`. 다크 값은 `:root:not([data-theme="light"]), [data-theme="dark"]`에 씁니다.
- 본문: `.mari-message-content`, 코드블럭: `.mari-md-codeblock` / `.mari-md-inline-code` / `.mari-md-codeblock-lang`
- 채팅 모드: `[data-chat-mode="roleplay"]` / `[data-chat-mode="conversation"]`, RP 폭 변수 `--mari-roleplay-message-column-width`
- RP 배경: `.rpg-overlay`, `.rpg-vignette`, `img.mari-background`
- 인월드 문서: `.mari-roleplay-document`, 누들·슬럽 구역: `.mari-chrome-token-scope`, `.marinara-capability-noodle`
- 내보내기 형식: `marinara.theme-folder` JSON 안에 `marinara.theme` 매니페스트 하나

엔진이 이 구조를 바꾸면 해당 자리만 손보면 됩니다. 색 변수는 `extension.js` 상단의 `GROUPS` 배열, 요소 직접 스타일은 `STYLE_GROUPS` 배열에 한 줄씩 추가하는 구조입니다.

## 설치

1. **설정 → 고급 → 위험 구역**에서 "외부 확장 가져오기 허용"을 켭니다.
2. **설정 → 애드온 → 외부 확장**에서 이 저장소의 zip 또는 폴더(`manifest.json`, `extension.js`, `extension.css`)를 가져옵니다. GitHub 확장 관리자 확장을 쓰면 저장소 주소를 등록해 업데이트도 받을 수 있습니다.
3. 가져온 확장은 꺼진 상태로 들어옵니다. 코드 해시를 확인하고 **승인 → 활성화**합니다. 코드가 바뀔 때마다 다시 승인해야 합니다.

이 확장은 `marinara.extension` 종류로, 마리나라 페이지 안에서 그대로 실행됩니다(full page access). 페이지의 스타일을 읽고 바꾸는 일을 하므로 이 권한이 필요합니다. 코드를 확인한 뒤 승인하세요.
